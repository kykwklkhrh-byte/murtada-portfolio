تحكّم بموقعك من تلفونك

تضيف تطبيقاتك، تحدّث روابط التحميل، تحذف مشروع، أو تغيّر معلوماتك. النشر الحقيقي يتأكد من حساب GitHub مالك، مو من زر مفتوح لكل الزوار.

شنو تريد تسوي؟

املأ المعلومات واضغط إرسال؛ بعدها تأكّد من الطلب داخل GitHub حتى يظهر على موقعك.

إذا الصورة بجهازك وما عندك رابط، تگدر ترفقها بصفحة GitHub اللي راح تنفتح بعدين، قبل تأكيد النشر.

لرفع صورة من تلفونك، أرفقها داخل طلب GitHub قبل تأكيده.

شلون يننشر؟ تملأ الاستمارة، وتنفتح صفحة طلب على GitHub. تتأكد أنت من الطلب وتضغط Submit new issue (إرسال الطلب). النظام يتحقق من حسابك، يحفظ التعديل وينشره تلقائياً. أي شخص غير صاحب المستودع ما يگدر ينشر تغييرات على الموقع من هالطريقة.
