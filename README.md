# مرتضى ستار v4 — Flutter / Android

مشروع Flutter يجمع واجهة عناية عربية ذات تصميم هادئ مع أدوات فحص الجهاز والتنظيف الآمن، إضافة إلى مجموعة أدوات متقدمة اختيارية مستندة إلى النسخة السابقة.

## الوظائف

- الرئيسية: اسم وطراز الهاتف، نسخة Android، البطارية، نوع الاتصال، نسبة التخزين حين تتاح بيانات حقيقية. لا يعرض نسبة RAM أو «مؤشر صحة» مختلقاً.
- التنظيف: معاينة ملفات temp الخاصة بالتطبيق مع مربعات اختيار غير محددة في البداية، ثم تأكيد قبل حذف أي ملف؛ إعادة فحص المسار والحجم وتاريخ التعديل قبل الحذف.
- الشبكة: قياس استجابة HTTP وسرعة التحميل والرفع التقريبية من Cloudflare، وسجل نتائج محلي. قد يظهر الرفع «غير متاح» إذا تعذر الاختبار.
- إضافات: معلومات الجهاز والبطارية وعناوين الشبكة، فحص وصول TCP، محلل التخزين، كشف ملفات مكررة بـ SHA-256، ومجلدات فارغة. بعض الأدوات المتقدمة تتطلب تصريح التخزين الواسع ويجب استخدامه فقط بإذن صريح.
- الهوية: «مرتضى ستار»، واجهة عربية RTL، أيقونة MS، الحقوق © مرتضى ستار.

## الخطوات لبناء APK

تحتاج Flutter (إصدار حديث 3.32+) وAndroid SDK وJava 17.

```bash
bash setup.sh --prepare-only
flutter analyze
flutter test
flutter build apk --release
```

أو شغّل `bash setup.sh` لعمل كل الخطوات. يولد `flutter create` ملفات منصة Android المفقودة.

## البناء على GitHub من دون كمبيوتر

1. أنشئ مستودعاً فارغاً جديداً على GitHub.
2. ارفع **محتويات هذا ZIP مفكوكة** إلى جذر المستودع، بما فيها مجلد `.github`.
3. افتح تبويب **Actions** ثم **Build Android APK** واختر **Run workflow**.
4. بعد نجاح البناء، افتح التشغيل ثم **Artifacts → murtada-star-apk**، فكّ الضغط وثبّت `app-release.apk`.

إن بنيت نسخة release بهذا الإعداد دون توقيع نشر خاص، فستستخدم إعداد التوقيع الافتراضي الذي يولّده Flutter؛ إعداد توقيع إنتاجي مخصص مطلوب قبل نشر رسمي على المتجر.

## الخصوصية والسلامة

لا توجد حسابات أو خادم تطبيق. نتائج القياس تحفظ محلياً. عند اختبار السرعة تتصل بالخوادم الخارجية التي تتلقى عنوان IP العام. لا يمكن تنظيف cache التطبيقات الأخرى أو رفع سرعة الإنترنت بنقرة من تطبيق عادي.

**انتبه:** إذن `MANAGE_EXTERNAL_STORAGE` موجود فقط لأدوات إدارة الملفات الاختيارية، وهو إذن واسع وقد لا يكون مقبولاً لسياسات Google Play في هذا النوع من التطبيقات. من يريد نسخة للنشر العام ينبغي إزالة الإذن واستبدال أدواته بـ Storage Access Framework. أدوات الملفات المتقدمة تحتاج اختباراً يدوياً على هاتف حقيقي قبل الاعتماد عليها في الحذف.

هذه الحزمة **سورس Flutter** وليست APK جاهزاً. لم يُنفّذ فيها `flutter analyze` أو بناء APK لأن بيئة إعداد الحزمة لا تحتوي Flutter SDK.
